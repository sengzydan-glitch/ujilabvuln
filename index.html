04 / SECURITY CHECK

Mitigation notes

DEFENSE
  • Object access: Check authorization on the server for every requested record.
  • Reflected content: Use context-aware output encoding and safe DOM APIs.
  • Database queries: Use parameterized queries; never concatenate raw input into SQL.
  • Validation: Treat client-side checks as convenience, not a security boundary.
